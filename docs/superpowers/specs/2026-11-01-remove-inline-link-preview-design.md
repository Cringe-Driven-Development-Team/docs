# Удаление Inline Link Preview

## Цель и проверенные факты

Пользователь выбрал полное удаление Inline Link Preview: всплывающие страницы мешают чтению и сопровождаются скачками интерфейса. На просмотренных кадрах локальной записи длительностью 11,8 с видны preview на 0–7 с и изменения позиции после перехода к разделу со схемами на 8–11 с. Саму причинную связь всех смещений с плагином запись не доказывает.

Актуальный известный `origin/main` — `7def5bf7d231bb8c36860ccc90ec2648f536441c`; файлы интеграции не отличаются от проверенной локальной базы `b608905`. Перед реализацией база обновляется. В `package.json` установлен `@nolebase/vitepress-plugin-inline-link-preview` 2.21.1. Интеграция состоит из Markdown-transform в config, компонента/регистрации/CSS в теме, `canPreviewDocLink` и browser-проверок, ожидающих iframe.

## Подходы и выбранное решение

Рассмотрены временное отключение с сохранением зависимости и полное удаление. Пользователь выбрал полное удаление; временный режим и новый плагин на замену не нужны.

- Удалить зависимость и её записи lockfile, Markdown-transform, компонент/регистрацию/неиспользуемые импорты, специальные CSS preview и ставший ненужным `site/.vitepress/link-preview.ts`.
- Ссылки остаются штатными ссылками Markdown/VitePress. Hover не открывает popup/iframe, клики, якоря, история браузера и `SITE_BASE` сохраняют работу.
- Удалить только устаревшие unit-кейсы фильтра preview. Остальные проверки publishing/front-libs из `scripts/readability-links.test.ts` сохранить. В `check-readability.ts` заменить ожидания preview проверками обычных ссылок и отсутствия hover-попапов.
- Обновить активный `docs-site`: канонический `.agents`, зеркало `.claude` через `skills:sync` и установленную копию Codex после ревью с сохранением возможных параллельных изменений. Архивные спеки/планы не переписывать; превью веток Pages остаётся отдельным механизмом.

## Границы

Enhanced Readabilities с FullWidth и сохранёнными настройками, Tabs, Group Icons, Mermaid и Eraser остаются. Их зависимости/стили не удаляются вместе с preview. Текст страниц, ID заголовков, маршруты, sidebar и схемы не меняются. Существующий Mermaid-scroll hook не переписывается без воспроизводимой отдельной причины.

## Проверка и результат

- Выполнить типы, unit-тесты, проверку модулей, синхронизацию/валидацию скилла и сборку.
- В собранном сайте воспроизвести путь из видео: наведения на ссылки стратегий в offline/theory, затем переход к caching-strategies#networkonly; проверить отсутствие popup/preview iframe, работоспособность ссылки и положение целевого раздела после готовности Mermaid. Стабильное состояние после загрузки схем отделять от начальной асинхронной отрисовки.
- Проверить затронутые browser-секции (меню/навигация, плагины и якоря) на корневой и вложенной базе с соответствующей сборкой; сохранить проверки ширины, Tabs/иконок и OpenWiki. Не заявлять исчезновение всех скачков, если повтор видео показывает отдельную проблему после удаления preview.
- Результат — проверенная feature-ветка и PR с описанием удалённого поведения. Новый merge отдельно не поручен.
