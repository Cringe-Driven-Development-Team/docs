## 2. Проверенные факты

Проверено 2026-09-27 по истории `main` и переписке, в которой делались PR #8 и #9.

- В репозитории нет `CLAUDE.md`. Правила схем — в `.claude/skills/eraser-diagrams/SKILL.md`, обзор — в `README.md`.
- Схема `infra` (PR #8) показывает целевое состояние; факты сверялись с репозиторием
  `Cringe-Driven-Development-Team/infra`: `main` → `pulumi/bootstrap/` (bootstrap-стек, проект `infra-shared`,
  бакет стейта, DNS-зона), ветка `task-infra-1` → `pulumi/index.ts`, `ansible/`. Финальное ревью PR #8 нашло
  неточные подписи (`clouds.yaml` без пути, «ssh deploy»), которые исправлены только после сверки с кодом.
- Уроки раскладки из PR #8 (коммиты `12a089d`, `8d5e851`, `8a6f03d`, `3b9c649`):
  - стрелка DNS-зона → VPS 1 и стрелка VPS 1 → VPS 2 обе входили в VPS 1 справа: подпись одной ложилась на
    линию другой. Исправлено постановкой VPS 1 строго под DNS-зону — стрелка пошла вертикально без изломов;
  - стрелки к группе (`to` — id группы) входят у её левого верхнего угла; узел VPS 1 в этом углу делал
    стрелку «pulumi up» к группе похожей на стрелку к VPS 1. Исправлено тем, что угол оставлен пустым;
  - подписи иконок переносятся по ~100 px в 3–5 строк и при отступе 20 от рамки касаются границы группы;
    отступ 40 это снял;
  - подпись «ssh Ansible через VPS 1 (ProxyCommand)» переносилась на две строки при зазоре между узлами
    ~180 px и шла в одну строку при зазоре ~340;
  - из одной иконки три стрелки выходят с шагом ~16 px; сдвиг иконки выше или ниже давал худшие
    варианты (стрелки огибали группу, подпись прилипала к подписи соседней иконки);
  - изменение высоты группы (без сдвига узлов) перестроило маршрут чужой стрелки («ssh под deploy»
    получила зигзаг) — роутер глобальный.
- Ловушки из PR #8: прямой апостроф в «Let's Encrypt» давал `W_CONTENT_SANITIZED` в `bun run validate`
  (marked экранирует `'` в `&#39;`, sanitize-html раскодирует обратно, CLI видит расхождение), типографский `’`
  проходит; в `Textbox.text` (Markdown, GFM) пути `~/…` без обратных кавычек рискуют зачёркиванием.
- Превью ветки собирает отдельный запуск workflow Pages на `main` (`dispatch` из push ветки); в проверках PR
  у ветки `Pages / build` и `Pages / deploy` — skipped. Сборка с деплоем ~4 минуты. Ответ Pages —
  `Cache-Control: max-age=600`.
- Локально собирает схемы только владелец (Windows, Git Bash, Docker Desktop на WSL2); в Git Bash MSYS
  переписывает `/путь` и `VAR=/путь` в аргументах, `MSYS_NO_PATHCONV=1` это отключает; `scripts/docker.ts`
  передаёт аргументы Docker напрямую через `Bun.spawnSync`. При коммитах git печатает
  `LF will be replaced by CRLF` (включён `core.autocrlf`).

## 4. `CLAUDE.md`

Файл в корне, по-русски, не длиннее ~50 строк. Разделы:

1. Что за репозиторий — одна фраза и ссылка на `README.md`.
2. Схемы — правка только по скиллу `eraser-diagrams`; MVP в корне `diagrams/`, `diagrams/frozen-k3s/` не
   править; схемы описывают целевое состояние; факты — из кода `Cringe-Driven-Development-Team/infra`
   (`pulumi/`, `pulumi/bootstrap/`, `ansible/`), каждую подпись и связь сверять с исходником, связи не
   выдумывать; новая схема — строка в таблице README.
3. Сборка — `render`/`build`/`site` в Docker (Docker Desktop запущен), без Docker `DIAGRAMS_NATIVE=1`;
   перед коммитом `bun run typecheck && bun run test && bun run build`; `bun run site` из git worktree — нет.
4. Процесс — спеки `docs/superpowers/specs/YYYY-MM-DD-<тема>-design.md` и планы
   `docs/superpowers/plans/YYYY-MM-DD-<тема>.md` по-русски, в спеке раздел «Проверенные факты»; ветка и
   worktree в `.claude/worktrees/<имя>`; PR в `main`, ссылка на превью ветки в PR; коммиты
   `тип(область): что сделано` по-русски (`feat`, `fix`, `docs`, `ci`, `chore`); описание PR — «Что»,
   «Решения», «Проверка»; с плагином superpowers — brainstorming → спека → план → SDD.
5. Публичный репозиторий — никаких IP, CIDR, токенов, внутренних адресов.
6. Окружение: Windows — Bash-инструмент это Git Bash; `docker run -v …` из шелла с `MSYS_NO_PATHCONV=1`;
   рендерер только под Node (скрипты это учитывают); `LF will be replaced by CRLF` при коммите — норма.

## 5. Скилл `eraser-diagrams`

- Новый раздел «Раскладка» между «Сетка и размеры» и «Иконки» — уроки §2 как правила:
  роутер глобальный (менять один параметр, смотреть PNG после каждого рендера; размер группы тоже
  перестраивает маршруты); отступ 40 от рамки при длинных подписях иконок; две стрелки в узел с одной
  стороны — ставить цель так, чтобы стрелка шла прямо (например строго под источником); угол группы, куда
  входят стрелки к группе, держать пустым; несколько стрелок из одной иконки — шаг ~16 px, разводить цели
  по высоте; длинной подписи — горизонтальный участок длиннее текста (для ~40 символов зазор ~300+).
- «Известные ловушки»: апостроф `'` → `’`; `~` в Markdown `Textbox` → пути в обратных кавычках.
- Шаг 9 цикла правки: сборка превью не видна в проверках PR (отдельный запуск Pages на `main`, ~4 минуты);
  Pages кэширует 10 минут — обновлять с Ctrl+F5.
