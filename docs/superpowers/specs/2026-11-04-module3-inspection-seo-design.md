# Инспекция переменных и SEO в модуле №3

Статус: согласовано пользователем 2026-11-04. Изменение добавляет темы в план учебного модуля,
а не реализует функции приложения.

## Проверенные факты

- На исходном коммите `5c14f0c` в `site/modules/3/tracks/` три трека: React Hook Form, tRPC и Zod.
- Ерофей — `ManInTheCoat`, Денис — `iRedTea` в `site/modules/people.yaml`.
- Треку нужен исполнитель; граф и меню строятся из файлов треков автоматически.
- `scripts/modules-data.test.ts` закрепляет состав третьего модуля и нагрузку участников.

## Подходы

Предложен вариант двух треков и подзадачи Open graph внутри SEO; пользователь указал
исполнителей для этих двух треков. Он сохраняет устройство существующего модуля.
Обычные заголовки на странице модуля не добавили бы темы в граф и не позволили бы
назначить исполнителей. Отдельный подтрек Open graph избыточен для одного пункта
без отдельного исполнителя или подробного плана.

## Проверка

Проверить данные через `bun run modules:check` и `bun test scripts/modules-data.test.ts`;
посмотреть разобранные новые треки. Перед коммитом страниц — typecheck, общий набор тестов
и сборка. После сборки проверить названия, Open graph и навигацию новых страниц.
