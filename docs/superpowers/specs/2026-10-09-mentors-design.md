# Менторы трека вместо «Помогают»

## 1. Цель

Поле `help` трека на деле всегда означает ментора: во всех 8 треках с `help` стоят только Ярослав и Саша,
слой графа уже называется «Помощь менторов». Делаем это явной ролью: поле `mentors`, подписи «Менторы», в
нагрузке — «ментор в N». Роль «помогает» убираем. Это делается до выноса графа в пакет
`@tp-prepare/vitepress-module-graph`, чтобы пакет взял модель уже с менторами.

Готово, когда:

- во всех треках `mentors` вместо `help`, а оставшийся `help` роняет сборку с понятной ошибкой;
- ментором может быть только человек с `mentor: true` в `people.ts`;
- на графе, в карточках, на страницах треков, в списке треков и в нагрузке нет слов «помогает»,
  «помощь»; вместо них «ментор», «Менторы».

## 3. Решения

- Одна роль «ментор», без «помогает»: студенты на чужих треках сейчас не помогают; понадобится — вернём
  отдельным полем.
- Ментор — только человек с `mentor: true`. Так в `mentors` не попадёт студент по ошибке.
- Линия на графе остаётся пунктиром `[4, 3]`: её смысл не меняется.
- Старый адрес `?hide=help` не ломает страницу: неизвестный слой отбрасывается, как сейчас.

## 4. Данные и проверки

```yaml
mentors: [YarikMix, blackHATred]   # необязательно
```

Ошибка — `ModuleDataError` в формате `<файл>: <поле> — <что не так>`, в `parseTrack`.

| № | Правило | Поле | Текст ошибки |
| --- | --- | --- | --- |
| 1 | поля `help` нет | `help` | `поле заменено на mentors` |
| 2 | `mentors` — список строк | `mentors` | как у других списков строк (`strings`) |
| 3 | логин есть в `people.ts` | `mentors` | как у `do` (`checkLogin`) |
| 4 | у человека `mentor: true` | `mentors` | `<логин> не ментор: в people.ts нет mentor: true` |
| 5 | ментор не исполнитель трека | `mentors` | `<логин> уже исполнитель` |
| 6 | логины не повторяются | `mentors` | `<логин> повторяется` |

## 5. Модель и граф — `modules.ts`

- `Track.mentors: string[]` вместо `help`.
- `LinkKind`: `"mentor"` вместо `"help"`; `LAYERS = ["subtasks", "mentors", "related"]`.
- `buildGraph`: `showMentors = !filter.hide.includes("mentors")`; участники фильтра и связи `mentor` — как
  сейчас у `help`.
- `Load = { login, doing, mentoring }`.

## 6. Интерфейс

| Где | Было | Стало |
| --- | --- | --- |
| Слой в фильтрах | «Помощь менторов» | «Менторы» |
| Нагрузка | «7 треков +5 помощь» | «7 треков · ментор в 5» |
| Карточка человека | «Помогает · N» | «Ментор · N» |
| Карточка трека, шапка страницы | «Помогают» | «Менторы» |
| Карточка подзадачи, «Кто» | сторона «помогает» | «ментор» |
| Список треков | «; помогают: …» | «; менторы: …» |
| `ModuleList`, счёт людей | `do` + `help` | `do` + `mentors` |

Текст: `redis-sessions.md` — «ментор — Саша»; `site/modules/index.md` — «кто какой трек ведёт и кто
менторит».
