# Figma Embed — план реализации

> **Для исполнителя:** использовать `superpowers:executing-plans` или `superpowers:subagent-driven-development` после явного выбора пользователя. Выполнять задачи по порядку и отмечать шаги ниже. Пользователь выбрал `superpowers:executing-plans` 04.11.2026.

**Цель:** общий Figma Embed и первый виджет QR-экрана в разделе подключения 2FA.

**Архитектура:** Vue-компонент получает обычную Figma design-ссылку и заголовок.
Небольшая чистая функция проверяет URL и строит embed и ссылку для открытия Figma.
Официальный iframe управляет просмотром; Markdown только выбирает стартовый экран.

**Стек:** существующие VitePress `2.0.0-alpha.21`, Vue, TypeScript, Bun test и Puppeteer;
новых зависимостей нет.

**Спецификация:** [2026-11-04-figma-embed-design.md](../specs/2026-11-04-figma-embed-design.md).

## На что обратить внимание при ревью

1. Чужой URL, похожий домен, HTTP или неподдержанный маршрут — ошибка, а не произвольный iframe (задача 1).
2. `m=dev`, fragment и лишние query — не уводят просмотр в Dev Mode и не меняют стартовый узел (задача 1).
3. SSR и вложенная база превью — одинаковые абсолютные Figma URL, никакого обращения к `window` при сборке (задачи 1–2).
4. Мобильная или сохранённая узкая ширина статьи — iframe не расширяет страницу и не закрывает ссылку (задача 2).
5. Figma недоступна или просит вход — статья и обычная ссылка остаются доступны; заглушка теста не доказывает живой просмотр (задача 2).

## Task 1: Компонент и безопасные ссылки

**Интерфейсы:** экспорт `figmaUrls(input: string): { embed: string; source: string }`;
компонент `<FigmaEmbed url="..." title="..." />`. Невалидный URL выбрасывает `Error`
с понятным сообщением, а не возвращает пустой результат.

- [x] Добавить тесты преобразования ссылки, например:

  ```ts

  const { embed, source } = figmaUrls(input);
  const result = new URL(embed);
  expect(result.origin).toBe('https://embed.figma.com');
  expect(result.pathname).toBe('/design/7iaVDGiwzQk2vZIB5ogVlq/Cellestial');
  expect([...result.searchParams.keys()].sort()).toEqual(['embed-host', 'node-id']);
  expect(result.searchParams.get('node-id')).toBe('496-16027');
  expect(result.searchParams.get('embed-host')).toBe('docs.cellestial.ru');
  expect(result.hash).toBe('');
  ```
