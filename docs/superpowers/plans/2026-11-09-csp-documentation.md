# CSP: план описания действующего устройства

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Способ выполнения выбирает пользователь до начала реализации.

**Goal:** Заполнить страницу CSP объяснением устройства политики Cellestial с двумя схемами и актуализировать связанные упоминания.

**Architecture:** Caddy добавляет CSP к ответам BFF; браузер применяет ограничения при работе с ресурсами приложения. Одна существующая VitePress-страница содержит объяснение, таблицу директив, две встроенные Mermaid-схемы и источники. Соседние страницы ссылаются на неё.

**Tech Stack:** Markdown/VitePress, Mermaid, существующий `DiagramSection`, Bun tests и browser CLI репозитория.

**Spec:** [Согласованная спецификация](../specs/2026-11-09-csp-documentation-design.md).

## Общие ограничения

- Описывать действующий блокирующий режим без истории перехода с Report-Only.
- Не менять инфраструктуру, приложение, навигацию, renderer, зависимости и историю модулей.
- Сохранить даты и границы прежних проверок; новые наблюдения сопровождать своей датой и результатом.
- Утверждения о коде подтверждать удалёнными файлами на конкретном SHA и ссылками на строки.
- Не приписывать заголовку на HTTP 404 успешную загрузку приложения или браузерную проверку блокировки.
- Работать в `/home/oleg/2026_H2/docs/.worktrees/csp-documentation`, ветка `docs/csp-documentation`.
- Не редактировать и не перегенерировать OpenWiki; не добавлять реальные IP и секреты.

## Фокус проверки

- Режим: текст не называет действующую CSP наблюдательной; проверяется заголовком и чтением изменённых абзацев.
- Область разрешений: `'self'`, CDN и `data:` относятся к конкретным директивам; сверка каждой строки таблицы с конфигурацией.
- Доказательства: наличие заголовка не подменяет проверку браузерного сценария; отдельная проверка раздела источников.
- Схемы: CDN-запрос идёт прямо из браузера, разрешение CSP не обещает успешную загрузку; осмотр SVG и подписей.
- Чтение: обе lazy-схемы появляются, текст и таблица читаются на узкой ширине, ссылки и якоря работают; проверка собранной страницы.
