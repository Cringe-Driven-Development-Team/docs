# Стандарт читаемости новых страниц — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрепить выбранные четыре дополнения к стандарту читаемости в docs-site и обязательное чтение скилла в AGENTS.md.

**Architecture:** Точечная правка канонического скилла и корневой инструкции, затем существующий skills:sync для зеркала. Одна задача объединяет правила, пример, проверку применения и синхронизацию: отдельно они не дают завершённого результата.

**Tech Stack:** Markdown-инструкции, Bun, существующие тесты синхронизации, Python validator, свежие агенты для проверки применения.

**Spec:** `docs/superpowers/specs/2026-11-01-docs-site-readability-standard-design.md` — утверждена пользователем 01.11.2026.

## Global Constraints

- Меняются инструкции и их зеркало. Страницы сайта, данные модулей, маршруты, схемы, зависимости и конфигурация рендеринга не меняются.
- Новый линтер и обязательный браузерный прогон для каждой текстовой правки не добавляются.
- Правила не требуют переформатировать всю страницу ради небольшого дополнения или искусственно ограничивать длину абзацев.
- Прежние правила подтверждения фактов, Tabs, Group Icons, якорей и ширины сохраняются.
- Подробности оформления остаются в скилле и не дублируются в AGENTS.md.
- Исходное успешное поведение не выдавать за RED.
- Установленную пользовательскую копию docs-site обновлять с проверкой текущего содержимого, учитывая параллельную миграцию Mermaid; чужие новые правки не затирать.
- Изменения оформить отдельным PR; слияние требует отдельного поручения пользователя.

## Review Focus

- Новый раздел на существующей странице: стандарт применяется к дополнению, ранее написанные разделы не переписываются.
- Причина и следствие в связном тексте: агент сохраняет объясняющий абзац, не заполняет форматы ради форматов.
- Обязательная оговорка: остаётся видимой, сохраняет статус непроверенного плана и не прячется в details/Tabs.
- Разные типы информации: перечисление, сравнение и порядок действий представлены по смыслу; факты не теряются.
- Чужая новая версия docs-site: обновление канонической, зеркальной и установленной копий не затирает параллельные изменения.

## Файлы и обязанности

- `AGENTS.md` — явное требование прочитать docs-site перед созданием/существенным изменением страницы.
- `.agents/skills/docs-site/SKILL.md` — область применения, самопроверка, один пример; существующая таблица выбора остаётся единственным справочником форматов.
- `.claude/skills/docs-site/SKILL.md` — только результат `bun run skills:sync`.
- Существующие `scripts/skills-sync.test.ts` и validator — проверки формата/зеркала, без новых тестов на совпадение формулировок.
- Артефакты сравнительного задания — только в ignored workspace этого плана; не в `site/` и не в новом постоянном тестовом фреймворке.
