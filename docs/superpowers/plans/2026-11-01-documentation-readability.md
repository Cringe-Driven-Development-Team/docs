# Читаемость и структура документации — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перестроить каноническую документацию для чтения человеком, сохранив технический смысл, источники и историю, и подключить четыре согласованных плагина.

**Architecture:** Сохраняем VitePress и нынешнюю тему с модульным графом, добавляя публичные интеграции плагинов. Длинные документы делим по согласованной карте, короткие редактируем по необходимости. Переносы страниц, якорей, ссылок и проверок входят в одну задачу с соответствующим текстом.

**Tech Stack:** Bun, TypeScript, Vue, VitePress `2.0.0-alpha.21`, существующие Mermaid/Eraser/module-graph, Nolebase Readabilities/Inline Link Preview `2.21.1`, Tabs `0.9.1`, Group Icons `1.8.1`.

**Spec:** `docs/superpowers/specs/2026-11-01-documentation-readability-design.md` (согласована).
