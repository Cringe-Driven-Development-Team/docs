# Трек BFF на tRPC — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Документы трека `bff` описывают tRPC между клиентом и BFF вместо прокси `/api/v1` с overlay.

**Architecture:** Три страницы трека переписываются по спеке §4–§8; `scripts/bff-pages.test.ts` —
страж их содержания: каждая задача сначала меняет проверки своей страницы (RED), потом текст (GREEN).
Кода сервиса нет — только документация, примеры кода на страницах — иллюстрации.

**Tech Stack:** VitePress 1.6.4 + `vitepress-plugin-mermaid`, Bun 1.3 (`bun:test`), TypeScript 7.0.2.

**Spec:** `docs/superpowers/specs/2026-10-08-bff-trpc-design.md`

## Global Constraints

- Ветка `docs/bff-trpc`, worktree `.claude/worktrees/bff-trpc`. Коммиты по-русски: `тип(область): что сделано`.
- Перед коммитом: `bun run typecheck && bun run test`; сборка — `DIAGRAMS_NATIVE=1 bun run build`
  (Docker на маке не поднят), ожидаемо `site ok: N pages` без ошибок `check-site` и `check-mermaid`.
- Названия тестов в `scripts/bff-pages.test.ts` — по-русски (стиль файла).
- Безопасность не меняется: `__Host-Http-session`, refresh в BFF, `X-CSRF: 1`, `Origin`, `Sec-Fetch-Site`,
  `SameSite=Strict`, Bearer к Go, две VPS и `X-BFF-Key`. Цитаты RFC 10017 не трогать.
- Заголовки разделов, которые остаются, не менять (якоря). Переименовываются только:
  «Один источник» → «Источники правды», «Какие запросы BFF пропускает» → «Какие вызовы BFF принимает»,
  «Как BFF проксирует запрос» → «Как BFF обрабатывает вызов».
- Утверждения о коде — со ссылкой на файл и строку на SHA: Go `4094350`, фронт `344ad0b`, infra `2f97437`.
- Примеры кода с именами схем Orval — с пометкой «точные имена — по выгрузке».
- Публичная репа: никаких IP, CIDR, токенов, внутренних адресов.
- Не трогать: `diagrams/`, `site/security/csrf/`, прошлые спеки.
