# Менторы трека вместо «Помогают» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поле трека `help` заменить на `mentors` с проверкой `mentor: true`, а «помогает» в интерфейсе — на «ментор».

**Architecture:** Задача 1 меняет модель (`modules.ts`), данные 8 треков и тесты модели. Задача 2 — Vue-компоненты, тексты и спеки, сборку и проверку в Chrome.

**Tech Stack:** TypeScript, bun test, VitePress 1.6.4, Vue 3, force-graph 1.51.4.

**Spec:** `docs/superpowers/specs/2026-10-09-mentors-design.md`

## Global Constraints

- Ошибки — `ModuleDataError` в формате `<файл>: <поле> — <что не так>`; тексты — из спеки §4 дословно.
- Линия ментора — пунктир `[4, 3]`, как была у `help`.
- Подписи — из таблицы спеки §6 дословно: «Менторы», «ментор в N», «Ментор · N», «ментор», «; менторы: …».
- Перед коммитом: `bun run typecheck && bun run test`; в конце — `DIAGRAMS_NATIVE=1 bun run build`.

## Review Focus

- `help: []` (пустой список) в треке — тоже ошибка «поле заменено на mentors», а не молчаливое чтение.
- `?hide=help` в адресе — отбрасывается, граф со всеми слоями (тест в задаче 1).
- Ментор на треке без `do` (родитель подтреков, как `profile`) — связь `mentor` есть, трек виден в
  фильтре по ментору (тест в задаче 1).
- Фильтр по ментору при скрытом слое `mentors` — треки, где он только ментор, скрыты (как было с `help`).
- В собранном сайте не осталось «помогает»/«Помогают»/«помощь» в шапках треков и списке под графом
  (проверка в задаче 2).
