# Исправление ссылок OpenWiki на главной — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Способ выбирает пользователь до начала реализации.

**Цель:** кнопка OpenWiki и карточка «Найти сведения» открывают визуализатор в текущей вкладке без 404 VitePress.

**Архитектура:** добавить `target: _self` обеим ссылкам frontmatter, повторяя существующее решение верхнего меню. VitePress оставит переход браузеру; отдельная HTML-страница визуализатора загрузится полностью.

**Стек:** Markdown/frontmatter, VitePress 2.0.0-alpha.21, Bun; установленный Puppeteer для браузерной проверки.

**Спецификация:** [согласованный документ](../specs/2026-11-04-openwiki-home-links-design.md).

## Общие ограничения

- Работать в `.claude/worktrees/openwiki-home-links`, ветка `fix/openwiki-home-links`.
- Адрес остаётся `/openwiki/` с учётом `SITE_BASE`, вкладка текущая.
- Продуктовая правка — два поля в `site/index.md`; новые зависимости, обработчики, маршруты и генерация wiki не нужны.
- Не добавлять тест, зеркалящий два декларативных поля: ошибку проверять настоящими браузерными кликами.
- Спецификация и план пока не закоммичены; включить их в коммит после обязательных проверок.

## Фокус ревью

- Обе ссылки главной: после гидратации VitePress открывают визуализатор.
- Вложенная база: переход не уходит из превью на корень сайта.
- Текущая вкладка: новый документ появляется в той же странице браузера.
- Back: возвращает главную, повторный переход также работает.
- Reload: визуализатор открывается напрямую после перезагрузки.

Все пять сценариев покрываются шагом 4 единственной задачи.

## Task 1: исправить обе ссылки и проверить переходы

**Файлы:** изменить `site/index.md`; сохранить спецификацию и этот план с результатами выполнения.

**Интерфейсы:** используются `hero.actions[].target` и `features[].target`, поддерживаемые штатной темой VitePress. Новых интерфейсов нет.

- [x] **1. Зафиксировать воспроизведение до правки.** На опубликованной главной дождаться гидратации `#app.__vue_app__`, затем независимо кликнуть `.VPHero a[href$="/openwiki/"]` и `.VPFeature[href$="/openwiki/"]`. Ожидается 404 VitePress; прямой переход на `/openwiki/` открывает визуализатор. Сохранить результат в журнал выполнения выбранного скилла.
- [x] **2. Исправить frontmatter.** В `site/index.md` добавить `target: _self` к действию `text: OpenWiki` и карточке `title: OpenWiki`, рядом с `link: /openwiki/`.
- [x] **3. Выполнить обязательные проверки.** В worktree подготовить зависимости по lockfile; выполнить `bun run modules:check`, `bun run typecheck`, `bun run test`, `bun run build`. Без Docker использовать `DIAGRAMS_NATIVE=1 bun run build`. Ожидаются нулевые коды выхода; ошибки сохранять полностью.
- [x] **4. Проверить исправленный сайт в браузере.** Раздать собранный `dist` обычным статическим сервером без SPA fallback; подход сервера и Puppeteer взять из `scripts/check-readability.ts`. Для каждого из двух селекторов шага 1 дождаться гидратации, записать временный маркер в `window`, кликнуть и проверить: URL равен `${SITE_BASE}openwiki/`, маркер исчез, появился `html[data-static-export="true"] .wiki-page-provenance`, вкладка та же. Выполнить reload, убедиться в наличии того же содержимого; Back возвращает `.VPHome`, повторный клик снова открывает визуализатор. Проверить обе ссылки сначала при `/`, затем после сборки `SITE_BASE=/branches/openwiki-home-links/ DIAGRAMS_NATIVE=1 bun run build` при той же базе сервера. Это разовая проверка, новый постоянный тестовый скрипт не требуется.
- [x] **5. Проверить существующую навигацию.** Для каждой из двух сборок выполнить `SITE_BASE=<база сборки> CHROMIUM_PATH=<установленный Chrome> bun scripts/check-readability.ts hierarchy`. Ожидается успешное завершение; оно дополнительно проверяет существующий переход в OpenWiki из документации.

Закоммитить `site/index.md`, спецификацию, план и журнал выбранного скилла сообщением `fix(docs): исправить переходы в OpenWiki с главной`.
