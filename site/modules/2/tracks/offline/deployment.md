# Размещение и обновление

::: info Сделано
Реализация и проверенные сценарии описаны в [офлайн-режиме](/documentation/offline/),
связь инструментов и настроек — в [сборке и регистрации SW](/documentation/offline/build-and-registration).
Ниже сохранён учебный план и его архитектурные объяснения.
:::

Здесь распределена ответственность за офлайн-комплект из [архитектуры Cellestial](./architecture).
Это целевое устройство трека, а не подтверждение готовой реализации.

## Адрес и scope

- **Адрес SW:** `https://cellestial.ru/sw.js` — стабильный публичный адрес.
- **Scope:** `/`; вместе с origin он ограничивает управление страницами.
- **Размещение:** на origin приложения, независимо от CDN base JS/CSS и каталога выпуска.

Origin и scope не запрещают контролируемой странице обращаться за ассетами к CDN.
[Scope и управление — Chrome](https://developer.chrome.com/docs/workbox/service-worker-lifecycle).

## Кто за что отвечает

| Участник | Ответственность |
| --- | --- |
| Сборка | Подготовить согласованные файлы SW, офлайн-страницы и её ресурсов |
| Публичная статика BFF | Отдать комплект до персонального HTML-handler: без сессии, обращения к Go API и bootstrap |
| Браузер | Установить и активировать SW |
| SW | Выполнить предварительное сохранение офлайн-комплекта |
| CDN | Отдать основные JS/CSS SPA |

Параметры плагина и способ сборки студент выбирает и проверяет самостоятельно.

## Обновление комплекта

- **Согласованность:** SW, его кеш и офлайн-страница обновляются как согласованный комплект.
- **Открытая вкладка:** при появлении новой версии она может ещё использовать прежний контроллер;
  это поведение нужно объяснить.
- **Принудительная перезагрузка:** для работающей вкладки она не является универсальным решением.

[Обновление SW — Chrome](https://developer.chrome.com/docs/workbox/service-worker-lifecycle).
