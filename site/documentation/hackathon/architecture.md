# Как устроена поддержка

Целевая архитектура хакатона. Проследим за вопросом из блокнота: где открывается интерфейс, кто разрешает читать обращение и какие данные уходят во внешние сервисы.

## От виджета до хранилища

Денис встраивает страницу `/embed/chat` в один iframe на домене Cellestial. Внутри неё нет второй кнопки запуска. Для `/embed/*` политика CSP разрешает встраивание с того же origin. Открытие и закрытие сохраняют страницу блокнота. Прямой вход в виджет также требует сессию.

Support владеет контрактом `spec/support/openapi.json`, обращениями, назначениями и метаданными вложений. Identity подтверждает роль оператора. Для демо её выдают существующей учётке через SQL. Скрытой кнопки админки недостаточно: Support проверяет доступ и при прямом запросе. Чужое обращение недоступно автору даже по известному ID.

## Как приходит ответ без WebSocket

Отправка создаёт сообщение один раз. Пока диалог открыт, виджет и экран оператора каждые 3 секунды запрашивают изменения через BFF. Курсор указывает, какие сообщения клиент уже получил. Даже если новых реплик нет, ответ содержит текущий статус: например, пользователь увидит, что оператор уже взял обращение.

Чтение истории не вызывает модель повторно. При таймауте автор может позвать человека. Кнопка и явная просьба в тексте используют одну операцию передачи. После неё Support отбрасывает поздний ответ модели, а после закрытия виджета клиент прекращает опрос.

## Как приложить фото или лог

До отправки виджет показывает имя и размер выбранного файла. Для первого сообщения сначала создаём текстовое обращение и получаем ID сообщения. После обрыва загрузки повторяем её с теми же ID. Ссылка на загрузку даёт доступ к одному временному объекту.

Support сверяет владельца, обращение, фактический размер и тип, для JPEG и PNG создаёт растровое превью. Оригинал после подтверждения хранится отдельно от временного объекта. Браузеру достаточно подписанного URL; ключ S3 остаётся на сервере.

## Как собеседник открывает вложение

Для фото виджет получает превью с origin Cellestial и открывает его в ImagePreview. Для лога показывает имя, размер и действие «Скачать». Support проверяет доступ к обращению заново при каждом запросе. Файл и подписанные ссылки остаются вне запроса к модели.
