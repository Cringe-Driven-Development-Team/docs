# Документация работающего продукта

Здесь перечислено только поведение, наблюдавшееся на [cellestial.ru](https://cellestial.ru).
Проверка 31.10.2026 в 13:11 UTC проведена в чистом Chrome; подробные результаты,
SHA выкладок и ссылки на источники собраны в [проверенной части BFF](/documentation/bff).

## Что подтверждено на проде

| Возможность или проверка | Дата и свидетельство | Подробности |
| --- | --- | --- |
| Гостю доступна форма входа | 31.10.2026, браузер: `/` → `302` на `/login` → `200`, видна форма | [Гостевой маршрут BFF](/documentation/bff) |
| Гостевой bootstrap не содержит пользователя и не устанавливает cookie | 31.10.2026, HTML `/login`: `user: null`, список cookie пуст | [Проверка BFF](/documentation/bff) |
| tRPC отклоняет GET без CSRF-заголовка | 31.10.2026, `GET /api/trpc/users.me` без `X-CSRF`: `403`, `csrf_invalid` | [Проверка BFF](/documentation/bff) |
| После CSRF-проверки tRPC требует сессию | 31.10.2026, тот же GET с `X-CSRF: 1`: `401`, «Нет сессии» | [Проверка BFF](/documentation/bff) |
| Прежний публичный маршрут пользователя недоступен | 31.10.2026, `GET /api/v1/users/me`: `404 Not Found` | [Проверка BFF](/documentation/bff) |

Это подтверждает гостевой маршрут браузер → BFF. Вход и регистрация, авторизованный
участок BFF → Go, refresh, выход, блокноты и POST-защита от чужого Origin этой проверкой
не подтверждены. Они остаются [планом трека BFF](/modules/2/tracks/bff).

## Архитектура, безопасность и эксплуатация

- [Архитектура](/architecture/) отделяет проверенный маршрут BFF от исторических схем MVP.
- [Безопасность BFF](/documentation/bff) описывает наблюдаемые ответы CSRF и проверки сессии.
  [Прежний раздел CSRF](/security/csrf/) сохранён как история проверки 07.10.2026;
  его Double Submit Cookie не описывает проверенный гостевой маршрут.
- Для эксплуатации: [свидетельства production-выкладок и граница проверки](/documentation/bff),
  [инфраструктурный репозиторий](https://github.com/Cringe-Driven-Development-Team/infra).
  Успешная выкладка сама по себе не доказывает работоспособность пользовательского сценария.
- [Контекст проекта и владельцы сведений](/project-context) помогают найти исходники,
  контракт API и правила команды. Реализация BFF принадлежит frontend, Go API — backend,
  инфраструктура — infra; ссылки на проверенные версии приведены на странице BFF.

## Где находятся планы и OpenWiki

[Модули](/modules/) содержат планы учебной работы, а не перечень уже работающих возможностей.

остаётся в документах этого репозитория. При расхождении проверь дату и свидетельство
в исходной странице, а состояние продакшена — на стенде.
