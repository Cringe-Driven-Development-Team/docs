# Обзор продукта

Cellestial — веб-приложение для работы с Python-блокнотами. Блокнот объединяет код, Markdown и результаты вычислений. Пользователь редактирует ячейки в браузере и запускает код в отдельном окружении. [Согласованный сценарий](/modules/2/tracks/file-exec).

## Из чего состоит продукт

| Объект | Назначение |
| --- | --- |
| Аккаунт | Вход, настройки профиля и доступ к своим блокнотам |
| Блокнот | Упорядоченные ячейки с Python-кодом и Markdown. У ячеек с кодом есть исходники и результаты запуска |
| Окружение исполнения | Запускает код по команде. Runtime-сессия связывает окружение с блокнотом, очередью и результатами |

## Решения и ограничения

- Исполнение берёт сохранённый код. При ошибке или конфликте сохранения сначала восстановите запись и затем повторите запуск. [Контракт](/modules/2/tracks/file-exec/contract).
- Создание блокнота и ввод текста доступны без запуска окружения. Сохранённые исходники и результаты остаются после завершения runtime-сессии. [Требования к окружению](/modules/2/tracks/notebook-vps).
- Базовый редактор охватывает Python и Markdown. Автокомплит, мультикурсор и расширенные команды отложены. Импорт `.ipynb` описан отдельным сценарием за пределами проверки базового редактора. [Границы плана](/modules/2/tracks/file-exec).
- Прод учебный. Преподаватели проверяют его примерно раз в месяц. Между проверками допустимы временная недоступность и несовместимость фронта и бэка. Поддержку старых клиентов и безостановочную выкладку владелец может потребовать для отдельной задачи. [Правила проекта](https://github.com/Cringe-Driven-Development-Team/docs/blob/8b12ddbb1ba47be5381181f1b334833f94b6fdf5/AGENTS.md#L9-L19).

## Что известно о готовности

Публично проверены открытие страницы входа гостем, ответы HTTP без сессии и офлайн-страница после установки service worker. Для авторизации, записи и запуска кода есть описание исходников. [Проверки и версии](/documentation/current-state), [реализация блокнотов](/documentation/notebooks/), [устройство Frontend](/documentation/frontend/).

## Уточнение требований {#открытые-вопросы-для-обсуждения}

Поиск должен находить исходники ячеек и локальные черновики. Вывод исполнения находится за пределами поиска. Приоритет новых возможностей фиксируют в [модулях](/modules/). [Требования к поиску](/modules/2/tracks/file-search), [задача #42](https://github.com/Cringe-Driven-Development-Team/frontend/issues/42).
